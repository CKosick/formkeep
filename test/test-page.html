FormKeep Test Environment

Use this page to verify all Acceptance Criteria for the FormKeep Chrome extension.

Acceptance Test Steps:
  1. Type paragraphs into the text fields below.
  2. Click "Simulate Crash / Clear Fields" to wipe the inputs.
  3. Click the FormKeep extension icon in the toolbar, or right click any field and choose "FormKeep: Restore text", or press Alt+Shift+R.
  4. Notice the text is fully restored with undo history intact!
  5. Check the password field test below to verify passwords are NEVER saved.

1. Standard HTML Form (Textarea & Input) Capture Enabled

2. ContentEditable / Rich Text Editor Gmail & Reddit Target

3. Password Fields & Sensitive Authentication Strictly Excluded

FormKeep has built-in hard exclusion for password fields, PINs, and security credentials. Even if typed, they must never be saved to IndexedDB or memory.

4. Automated Test Verification Checks

Run the in-browser verification checks against the FormKeep local IndexedDB database.
